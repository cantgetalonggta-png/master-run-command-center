Deployment

This build is pure static (no server runtime). Hosts: GitHub Pages, Vercel static, any CDN. Framework: none required — single index.html + data/ + media/.

  • Root directory: site root with index.html
  • No build step required for production
  • Optional: GitHub Action pages deploy from /docs or /
  • Vercel: Framework Preset = Other, Output = site root
